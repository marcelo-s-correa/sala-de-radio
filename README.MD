# 📻 Sala de Rádio

Projeto de comunicação por rádio estilo PTT (Push-To-Talk) utilizando conexão **P2P (peer-to-peer)** com PeerJS.

---

## 📌 Sobre o Projeto

O **Sala de Rádio** é um projeto desenvolvido com o objetivo de simular uma comunicação via rádio em tempo real, permitindo interação entre usuários de forma simples e direta.

A proposta é recriar a experiência de rádios comunicadores (walkie-talkie), utilizando tecnologias web modernas e conexão direta entre peers.

---

## ⚙️ Tecnologias Utilizadas

- **HTML** – Estrutura da interface  
- **CSS** – Estilização e layout  
- **JavaScript** – Lógica de comunicação  
- **PeerJS** – Conexão P2P em tempo real  

---

## 🎙️ Funcionalidades

- Comunicação em tempo real entre usuários  
- Sistema PTT (Push-To-Talk)  
- Conexão direta P2P (sem servidor intermediário de mídia)  
- Interface simples e intuitiva  

---

## 🎯 Objetivo

O projeto tem como finalidade:

- Estudo de comunicação em tempo real via WebRTC  
- Exploração de conexões P2P utilizando PeerJS  
- Simulação de um sistema de rádio digital  
- Proporcionar uma experiência divertida entre amigos  

---

## ⚠️ Observações

Este projeto é voltado para fins de estudo e entretenimento, não sendo recomendado para uso profissional ou aplicações críticas.

---
